## Tasks

### Task 1: Source Discovery & Data Preparation
- Used Chapter 6 (Neural Networks) from the Jurafsky & Martin textbook
- Extracted and cleaned text from the PDF using PyMuPDF
- Split the text into 150 chunks of 500 characters with 50 character overlap
- Created 20 Question-Answer pairs based strictly on Chapter 6 content

### Task 2: Technique Comparison — Naive RAG vs Contextual Retrieval

**Naive RAG:**
- Chunks are embedded directly without any additional context
- Uses cosine similarity to retrieve the top 5 most relevant chunks
- Retrieved chunks are passed to the LLM to generate an answer

**Contextual Retrieval:**
- Each chunk is enriched with a 1-2 sentence context prefix generated by the LLM
- The enriched chunk is then embedded and stored in the vector database
- This helps the retriever understand where in the document each chunk comes from

**Evaluation Results (ROUGE Scores):**

| Method               | ROUGE-1 | ROUGE-2 | ROUGE-L |
|----------------------|---------|---------|---------|
| Naive RAG            | 0.5653  | 0.3925  | 0.4884  |
| Contextual Retrieval | 0.5114  | 0.3479  | 0.4555  |

**Discussion:**  
Naive RAG scored higher on ROUGE metrics because it retrieves chunks that closely 
match the exact wording of the ground truth answers. Contextual Retrieval produces 
more detailed and informative answers but uses different wording, which results in 
lower ROUGE scores. In a real-world setting, Contextual Retrieval would likely 
provide better answers to users.

### Task 3: Web Application
- Built a simple chatbot using Streamlit
- The chatbot uses Contextual Retrieval to answer questions about Chapter 6
- Each answer displays the source chunks used to generate the response

## How to Run

### 1. Clone the repository and set up the environment
```
pip install transformers torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install PyMuPDF groq rouge-score streamlit jupyter python-dotenv
```

### 2. Set up API key
Create a `.env` file in the root folder:
```
GROQ_API_KEY= groq_api_key
```

### 3. Run the notebook
Open `A6_main.ipynb` in VS Code and run all cells in order.

### 4. Run the web app
```
streamlit run app/app.py
```
